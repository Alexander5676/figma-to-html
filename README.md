# WashWise — PWA-гид по стирке

Современное веб-приложение на Next.js, React и Tailwind CSS, которое помогает понять, как часто стирать разные вещи, при какой температуре и на каком режиме.

## Возможности

- Карточки вещей с категорией, частотой стирки, температурой и режимом.
- Поиск по названию вещи.
- Фильтр по категориям: дом, спорт, повседневка, базовое.
- Избранное с сохранением в `localStorage`.
- Тёмная тема с сохранением в `localStorage`.
- PWA: `manifest.json`, иконка приложения и service worker для установки и базового офлайн-кэша.
- Адаптивная сетка карточек, hover-анимации и современный UI.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000).

## Проверка функциональности

1. Введите название в поле поиска, например `джинсы`.
2. Выберите категорию, например `спорт`.
3. Нажмите сердечко на карточке и перезагрузите страницу — избранное сохранится.
4. Переключите тёмную тему и перезагрузите страницу — тема сохранится.
5. Откройте приложение в браузере с поддержкой PWA и установите его через кнопку установки в адресной строке или меню браузера.

## Структура файлов

```text
app/globals.css        # глобальные стили Tailwind и dark-вариант
app/layout.tsx         # metadata, viewport, manifest
app/page.tsx           # главный экран, поиск, фильтр, localStorage, регистрация SW
components/Card.tsx    # карточка вещи
components/Header.tsx  # hero/header и переключатель темы
utils/storage.ts       # функции работы с localStorage
public/manifest.json   # PWA manifest
public/sw.js           # service worker
public/icon.svg        # иконка приложения
```
